# Are AI-Generated Song Lyrics Less Diverse Than Human-Written Lyrics?

Analysis code, AI-generated lyrics, and results for the paper
**"Are AI-Generated Song Lyrics Less Diverse Than Human-Written Lyrics? Comparing Semantic and Lexical Diversity"**,
which received the **Excellence Award** at the 10th International Junior Academic Competition (IJAC) 2026.

Author: Ashton Jung (Troy High School, USA)

## Summary

A matched comparison of human-written songs and lyrics generated by Claude Sonnet 4.5 across three sampling
temperatures. Semantic diversity is measured with sentence embeddings (all-mpnet-base-v2) and lexical diversity
with MTLD, adjusting for genre and lyric length. The manuscript is not included in this repository.

## Repository layout

| Path | Contents |
|---|---|
| `src/` | Numbered analysis pipeline (`01_` … `11_`), run in order |
| `data/generated/` | Raw AI-generated lyrics with generation metadata (`ai_lyrics_raw.jsonl`) |
| `data/processed/` | Generation prompts (no lyric text), AI lyrics after quality control, song-level features |
| `outputs/` | Figures, tables, model results, exclusions, pre-analysis decisions |
| `requirements.txt` | Python dependencies |

## What is not included

The human-written lyrics (source corpus) are **not** redistributed because they are copyrighted. For that reason
the early pipeline steps (`01`–`03`, and the parts of `05`–`11` that read the human lyric text or embeddings)
cannot be re-run from this repository alone. The AI-generated lyrics, the prompts, the song-level features and
all reported tables and figures are included so the results can be inspected and checked.

## Generation notes

`generation_method` in the AI-lyrics files records how each lyric was produced. The lyrics were generated mainly with
Claude Sonnet 4.5 (`claude-sonnet-4-5-20250929`) through the Anthropic API. A smaller number were produced
through a Claude Code session or the Claude Code CLI; the model and method for every lyric are recorded in the
`model` and `generation_method` columns of the data files.
